# Examples

Tiny sample projects used to test the skill. Open one in Claude Code and try:

- `make the pricing card more modern` → asks, then 10 variants
- `make it look more professional, keep the brand blue #1D4ED8` → variants, blue kept everywhere
- `change the CTA color to #16A34A` → no variants, direct edit
- `fix the button overlapping the text on mobile` → no variants, bug fix
- `redesign the hero, just one version please` → no question, one version

`plain-html/` is a static page. `react-tailwind/` is the same page as React components with a Tailwind theme (`brand` color).
